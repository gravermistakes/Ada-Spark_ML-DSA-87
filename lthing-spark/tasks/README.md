migration.

Current sources of truth are production code, the root README/CLAUDE files,
`lthing-spark/CLAUDE.md`, `TEST_COVERAGE_ANALYSIS.md`, and fresh
`make build tools test prove` output.

References here to `LTHING_MLDSA65`, `LTHING_MLDSA87`,
`Arithmetic_Core_Complete`, reject-only KAT gates, or SPARK-off production
crypto are historical.
